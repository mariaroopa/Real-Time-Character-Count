## Real-Time-Character-Count
A simple and interactive Real-Time Character Counter built using HTML, CSS, and JavaScript.
It updates the character count instantly as the user types, displays the number of characters used and remaining, prevents input beyond the maximum limit, and provides a warning message when the limit is reached. This project demonstrates JavaScript event handling and dynamic DOM manipulation.

## Purpose:
To practice real-time input validation, DOM manipulation, and JavaScript event listeners while creating a user-friendly text area with a live character counter.
